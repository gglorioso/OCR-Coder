3. Why Your Study is Unique
Most existing research focuses on Semantic Accuracy 
(Did the model answer the question correctly?). 
Your "Syntactic Texture Probes" go deeper.

By looking at indentation style and nesting depth, 
you are essentially testing Spatial Topology preservation.
Standard papers don't usually measure if a model "perceives" 
the difference between 4 spaces and a tab; they only care 
if it can read the variable name. Finding the "knee" where
a model can still "see" code structure but can no longer "read" 
keywords would be a significant contribution to VLM 
interpretability.


The Test: Show the model an image where 
the code is perfectly indented (Structure) 
but the text is actually just random Greek 
letters (Fake Semantics).

The Result: If the model says, "This looks like a nested 
Python function," it proves the Vision Encoder is 
extracting Code-Specific Topology.

Why this is a mic drop: No one has ever proven that VLMs have a
"Mental Model" of what code looks like independent of
the words. If you prove that, you've discovered a new 
way the "transplanted brain" perceives its world
